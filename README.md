Project Jarvis C Compiler goals: 
1. 16, 32, and 64 bit development environment for C99 programming language. 
2. The solution is designed to be a complete toolchain for C99 development, including an IDE, compiler, assembler, linker, librarian, preprocessor, and binary dumper. 
3. Provide a robust and efficient development environment for C99 programming on x86 and x64 architectures.
4. Output formats include 16 bit dos, 16 bit windows, 32 bit windows, and 64 bit windows executables.
5. included in the project types is an operating system development environment for C99 programming language.
6. 16 bit, 32 bit, and 64 bit flat binary output included as well.
****
The tech stack for the project includes the following components:
1. Visual Studo 2026 for all components of the project.
2. CoPilot AI (built-in to Visual Studio) heavily used for code generation and assistance.
