Project Jarvis C Compiler
goal: 16, 32, and 64 bit development environment for C99 programming language. The solution is designed to be a complete toolchain for C99 development, including a compiler, assembler, linker, librarian, preprocessor, and binary dumper. The goal is to provide a robust and efficient development environment for C99 programming on x86 and x64 architectures.
****
| Project           | Host      | Purpose                                    | Status        
| ----------------- |-----------| ------------------------------------------ | ------------- 
| Compiler          | x86 x64   | C99 to JWasm assembler                     | Planned using AI   
| Assembler         | x86 x64   | JWasm assembler to binary object file      | Planned using AI 
| Jarvis IDE        | x86 x64   | Development Environment                    | Planned using AI     
| Linker            | x86 x64   | binary objects and libraries to executable | In Progress using AI
| Librarian         | x86 x64   | binary objects to library                  | Planned using AI
| Preprocessor      | x86 x64   | preprocesses C99 source code               | Planned using AI
| Binary Dumper     | x86 x64   | extracts binary information                | Planned using AI
